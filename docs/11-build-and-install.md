# Ω7 — Budowanie i instalacja

1. Zainstaluj aktualne Android Studio oraz wymagane Android SDK.
2. Otwórz katalog `omega7-messenger` jako istniejący projekt.
3. Wykonaj synchronizację Gradle.
4. Zbuduj wariant `debug` dla testów albo `release` po skonfigurowaniu podpisywania.
5. Uruchom na emulatorze lub fizycznym urządzeniu testowym.

Projekt nie zawiera żadnych kluczy podpisujących, tokenów ani sekretów.

W tym środowisku nie ma Android SDK/ADB ani pobranej dystrybucji Gradle, dlatego końcowy APK nie może zostać tutaj uczciwie wygenerowany ani przetestowany na urządzeniu.
