# Ω7 — Lista wydania

- [ ] Build produkcyjny z reprodukowalnym środowiskiem.
- [ ] Podpis aplikacji i bezpieczne zarządzanie kluczem podpisującym.
- [ ] SBOM i skan zależności.
- [ ] Audyt implementacji E2EE.
- [ ] Testy penetracyjne backendu i aplikacji.
- [ ] Testy na minimum kilku wersjach Androida i urządzeniach różnych producentów.
- [ ] Testy backup/restore i sprawdzenie, że sekrety nie wyciekają do backupu.
- [ ] Testy panic wipe.
- [ ] Testy wycieku przez logi, schowek, zrzuty ekranu i powiadomienia.
- [ ] Testy offline/online, duplikacji, restartów i braku sieci.
- [ ] Testy dostępności.
- [ ] Polityka prywatności, regulamin i procedura incydentowa.
- [ ] Monitoring bez zbierania treści wiadomości.
- [ ] Ostateczna niezależna weryfikacja bezpieczeństwa.
